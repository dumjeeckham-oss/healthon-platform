# Components

모든 카드는 radius 20px, shadow `0 4px 16px rgba(0,0,0,.08)`, 내부 여백 24px을 기본값으로 사용합니다.

| 컴포넌트 | 핵심 구성 |
|---|---|
| Primary Button | Leaf Green 배경, 흰 텍스트, 높이 56px |
| Secondary Button | 흰 배경, Divider 테두리, Health Green 텍스트 |
| Info Card | 아이콘 + 지표 + 보조 설명 |
| Challenge Card | 목표명 + 진행률 + 기간 |
| Forest Card | 나무 레벨 일러스트 + 성장 메시지 |
| Badge Card | 배지 + 획득 조건 + 날짜 |
| Family Card | 아바타 + 가족 구성원 상태 |
| Ranking Card | 순위 + 이름 + 걸음 수 |
| Notice Card | 공지 아이콘 + 제목 + 날짜 |
| AI Coach Card | 코치 제안 + 근거 + 행동 버튼 |

버튼은 최소 터치 영역 48×48px, 텍스트가 있는 버튼은 56px 높이를 권장합니다.
