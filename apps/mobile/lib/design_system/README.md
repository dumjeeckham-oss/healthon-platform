# HealthON Design System v2.0

“매일 조금씩 성장하는 건강한 숲”을 위한 앱 디자인 산출물입니다.

## 포함 내용

- 10종 5-layer 배경 SVG (`Sky > Cloud > Mountain > Forest > Ground`)
- 그라운드 6종, 나무 17종, 장식 12종, 날씨 8종, 동물 13종
- HealthON 아이콘 14종, 배지 6종
- Lottie JSON 16종, 짧은 UI 사운드 MP3 13종
- JSON/CSS/TypeScript 토큰과 React 컴포넌트 시작 파일

모든 SVG는 viewBox 기반이며 크기 변경이 가능합니다. 상업적 앱 프로젝트 내부 사용을 전제로 자유롭게 수정할 수 있습니다.
