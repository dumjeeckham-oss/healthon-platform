## 2026-08-06 — Health Sync Pipeline 구축

### 작업: Health Connect / Apple Health → Supabase 자동 동기화 파이프라인

#### 1단계: Domain Models + SQL Migration + Mapper
- `health_models.dart` — HealthDaily, HealthSyncLog, SyncStatus, HealthDevice enum
- `health_tables.sql` — health_daily (UNIQUE user_id,date), health_sync_logs, health_snapshots, upsert_health_daily RPC, get_health_weekly/monthly RPC, RLS
- `health_mapper.dart` — fromSupabase/toSupabase extensions

#### 2단계: Health Sync Service
- `health_sync_service.dart` — 장치 감지(Android/iOS), 권한 요청, 오늘/어제/특정날짜/기간 데이터 조회 (health 패키지 사용: STEPS, DISTANCE_DELTA, ACTIVE_ENERGY_BURNED, EXERCISE_TIME, MOVE_MINUTES)
- HealthSyncService는 HealthDaily 객체로 반환

#### 3단계: Repository
- `health_repository_interface.dart` — IHealthRepository (upsertDaily, getToday, getRange, getWeeklySum, getMonthlySum, getTotalSum, logSync 등)
- `supabase_health_repository.dart` — Supabase 구현체 (RPC upsert_health_daily, get_health_weekly, get_health_monthly)

#### 4단계: Riverpod Providers
- `health_provider.dart` (기존 대체) — healthRepositoryProvider, healthPermissionProvider, healthTodayProvider, todayStepsProvider, todayDistanceProvider, todayCaloriesProvider, weeklyStepsProvider, healthWeekProvider, healthMonthProvider, HealthSyncNotifier(healthSyncProvider)

#### 5단계: Health Permission Screen
- `health_permission_screen.dart` — 권한 요청 → 동기화 → PostSync 연쇄. Feature bullet UI.

#### 6단계: 연쇄 서비스
- `forest_sync_service.dart` — health_daily.steps 누적 → Forest tree 레벨/exp 계산 (Lv.1~8)
- `challenge_sync_service.dart` — health_daily.distance_km 합계 → challenge_progress 업데이트
- `mission_sync_service.dart` — 오늘 걸음 기준 daily_missions 완료 체크 + reward 지급 (exp/coin)
- `ranking_service.dart` — 주간/월간/전체/Family 랭킹 (health_daily 집계) (미완: Supabase query 문법 현행화 필요)
- `post_sync_orchestrator.dart` — Forest → Challenge → Mission → Snapshot 순차 실행
